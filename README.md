# 建築物工程技術服務建造費用計算器

依「機關委託技術服務廠商評選及計費辦法」附表「建築物工程技術服務建造費用百分比參考表」製作的服務費計算工具。
（英文法規名：Regulations for Selection and Fee Calculation of Technical Services Providers Entrusted by Entities）

## 怎麼開

單一檔案、零依賴，不需安裝任何東西：

- 直接用滑鼠雙擊 `index.html`，用瀏覽器開啟即可（離線可用）。

## 怎麼用

1. **輸入建造費用**：直接打數字，會自動加千分位逗號。
2. **選類別**：第一類～第四類（依建築物複雜度分類）。
3. **調整比率**（可不改）：設計及規劃費用比率預設 55%、監造服務費比率預設 45%。
4. 按「**計算服務費**」，下方會列出每個金額級距的累進計算明細，以及設計規劃費、監造服務費與總服務費用的加總。

## 費率想自己改？

按右上角「**編輯費率**」，表格會變成可輸入格；改完按「完成編輯」再計算即生效。
修改只在當前頁面有效，**重新整理頁面就會還原成預設費率**。

## 計算方式說明

採「累進計費」：建造費用切成 6 個金額級距（0~500萬、500萬~1,000萬、…、5億以上），每一段金額各自乘上該級距費率後加總，再按設計/監造比率拆分。
