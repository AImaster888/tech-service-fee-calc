# 工程技術服務建造費用計算器

依「機關委託技術服務廠商評選及計費辦法」第 29 條附表一～附表四製作的服務費計算工具。
（英文法規名：Regulations for Selection and Fee Calculation of Technical Services Providers Entrusted by Entities）

- 法規來源：https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=A0030077
- 附表 PDF 原件：[source/](source/) 資料夾（頁面上各分頁的「附表 PDF」鈕會直接開啟）

## 怎麼開

零依賴，不需安裝任何東西：

- 直接用滑鼠雙擊 `index.html`，用瀏覽器開啟即可（離線可用）。
- 要複製給別人用時，請把**整個資料夾**一起複製（「附表 PDF」按鈕需要 `source/` 資料夾在旁邊）。

## 四個附表

頁面上方有四個分頁鈕，點選切換：

| 分頁 | 內容 | 輸入 |
|---|---|---|
| **附表一 建築物工程** | 6 級距 × 第一～四類費率，服務費再按「設計及規劃」「監造」比率拆分（預設 55% / 45%） | 建造費用、類別、兩個比率 |
| **附表二 公共工程** | 6 級距，「設計及協辦招標決標」「監造」兩欄各自獨立費率 | 建造費用 |
| **附表三 專案管理（不含監造）** | 4 級距（3億／5億／10億分界）單一費率 | 建造費用 |
| **附表四 專案管理（含監造）** | 「壹 諮詢及審查」＋「貳 監造」兩段加總；監造依工程類型套建築物（分四類）或公共工程費率 | 建造費用、工程類型 |

## 怎麼用

1. 選好分頁，**輸入建造費用**（直接打數字，會自動加千分位逗號）。
2. 附表一另選類別與比率；附表四另選工程類型。
3. 按「**計算服務費**」，下方列出每個金額級距的累進**計算式明細**與加總。

附表一的「第五類」（歷史性建築等）法規規定比照服務成本加公費法編列、或比照第四類辦理，已以附註文字標示。

## 費率想自己改？

各分頁按「**編輯費率**」，表格變成可輸入格；改完按「完成編輯」再計算即生效。
修改只在當前頁面有效，**重新整理頁面就會還原成法規預設費率**。

## 計算方式說明

採「累進計費」（法規附註：百分比應按金額級距分段計算）：建造費用切成數個金額級距，每一段金額各自乘上該級距費率後加總。
