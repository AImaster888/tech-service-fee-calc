# 工程技術服務建造費用計算器

**版本 v1.3.2（2026-08-13）**

依「機關委託技術服務廠商評選及計費辦法」第 29 條附表一～附表四製作的服務費計算工具。
（英文法規名：Regulations for Selection and Fee Calculation of Technical Services Providers Entrusted by Entities）

- 法規來源：https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=A0030077
- 附表 PDF 原件：[source/](source/) 資料夾（頁面上各分頁的「附表 PDF」鈕會直接開啟）

## 怎麼開

零依賴，不需安裝任何東西：

- 直接用滑鼠雙擊 `index.html`，用瀏覽器開啟即可（離線可用）。
- 要複製給別人用時，請把**整個資料夾**一起複製（「附表 PDF」按鈕需要 `source/` 資料夾在旁邊）。

## 怎麼用

1. 選好分頁，**輸入建造費用**（直接打數字，會自動加千分位逗號）。
2. 附表一另選類別與比率；附表四另選工程類型。
3. 需要打折時，在費率表上方的「**折扣**」欄輸入折數（見下節）。
4. 按「**計算服務費**」，下方列出每個金額級距的累進**計算式明細**與加總。

附表一的「第五類」（歷史性建築等）法規規定比照服務成本加公費法編列、或比照第四類辦理，已以附註文字標示。

## 折扣（v1.1 新增）

各分頁費率表上方有「**折扣**」欄，用百分比填：輸入 `90` 就是打九折（費率再乘 0.9），預設 `100` 表示不打折。

- 一個折扣**統一套用**該分頁費率表的所有級距、所有類別。例：附表一填 90，則第一類 0~500 萬的 8.6%、500~1,000 萬的 8%、第二類的 9.3%……全部一律乘 0.9。附表四的三張表（壹、貳-一、貳-二）共用同一個折扣。
- 填了折扣後，**費率表**每格會在原費率下方加一行折後費率（例 `8.6%` → `×90% = 7.74%`）；**計算結果**每個級距在原算式下方加一行折後算式，最下方總計同時列出原價與折後金額。**原本的數字一律保留**，方便對照。
- 折扣維持 `100` 時不會出現任何「折後」字樣，費率表也不會多出小字。（取位原則仍照下方〈取位原則〉一節套用，不因是否打折而不同。）

## 費率想自己改？

各分頁按「**編輯費率**」，表格變成可輸入格；改完按「完成編輯」再計算即生效。
修改只在當前頁面有效，**重新整理頁面就會還原成法規預設費率**。

「編輯費率」與「折扣」可以併用：折扣是以你改過的費率為基數再打折。

## 計算方式說明

採「累進計費」（法規附註：百分比應按金額級距分段計算）：建造費用切成數個金額級距，每一段金額各自乘上該級距費率後加總。

### 取位原則（v1.3.1 起）

分三層，**不打折時也一樣適用**：

| 層級 | 規則 | 例 |
|---|---|---|
| **費率** | 折後費率**無條件捨去**到小數 2 位 | `3.6% × 90% = 3.24%`；`8.6% × 87.5% = 7.525%` → 取 **7.52%** |
| **明細金額** | 每個金額區間各自**無條件捨去**到小數 2 位 | `334,666,299.46 × 3.24% = 10,843,188.102504` → **10,843,188.1** |
| **加總／小計／總計** | **四捨五入到整數元**，不留小數 | `… + 10,843,188.1 = 15,095,688.1` → **15,095,688** |

- 明細留到分、加總取到元，所以相加後常會有零頭。**發生四捨五入時，該行會標出取整前的數字**，例如 `… = 15,095,688.1 → 四捨五入 15,095,688元`；本來就是整數的行不會多寫任何字。這樣算式左邊相加剛好等於箭頭前那個數，整行可以逐步核對。
- 費率只在「折後費率」這一層捨去。附表一的明細是「金額 × 費率 × 設計 55%／監造 45%」一次乘到底後才捨去，不會捨去兩次。
- 附表四的「壹 小計」「貳 小計」各自為該段明細之和（取整），總服務費用為兩個小計相加。
- 若「編輯費率」把某格改成超過 2 位小數（例 `8.666%`），即使不打折，計算也會以捨去後的 `8.66%` 為準，費率表會標示出來。

### 加總會列出組成算式

各項加總、小計、總服務費用都會寫出是哪幾項相加，例如：

```
設計及協辦招標決標費加總: 295,000 + 280,000 + 2,000,000 + 2,150,000 + 12,047,986.78 = 16,772,986.78 → 四捨五入 16,772,987元 (1677萬2987元)
總服務費用: 16,772,987 + 13,030,656 = 29,803,643元 (2980萬3643元)
```

只跨一個金額區間時沒有「加了哪幾項」的問題，該行就只顯示金額。
